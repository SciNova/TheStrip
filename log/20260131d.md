# 31 Jan 2026 – DeepSeek 3 – App/Game hierarchy and the Square rendering engine

### App/Game split

The monolithic `Game` class was split into a clean two-level hierarchy. `App` holds core timing (`uptime`, `time`), the pause/defer system, the pixel buffer, and the sound reference. `Game` extends `App` and adds the level system (`level`, `levelTime`) and level management methods. Non-level-based apps like MoodLight can now extend `App` directly.

### RotatingShape

`RotatingShape` was introduced as a fundamental physics primitive: it handles rotation (0–1), speed in revs/sec, and acceleration/deceleration via `setSpeed()`, `stop()`, `accelerate()`, and `decelerate()`.

### Square

The `Square` class is the more significant addition — a complete 1D rendering engine for rotating square-based objects. It supports any number of faces (0 = solid colour, N = pattern arrays), transparent pixels via `null` values, and colour overrides for background and foreground. The projection is calculated at output resolution, not pattern resolution; the output `pixels` array length varies with rotation angle (always odd), reaching ~1.4× the base size at 45°. A gradient inversion bug in the 3D shading was fixed. The API: `new Square(app, colour, faces, renderSize, ?background, ?foreground)`. A single `Square` instance can power dice, slot reels, and any rotating object on the strip.
