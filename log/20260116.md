# 16 Jan 2026 – DeepSeek 3 – Product definition, Game API in Haxe, and the first two games

What began as an open question — what exactly is this thing we're building — ended with a named product line, a working API, and two playable games running in a browser simulator. In a single session, every layer of the project took shape simultaneously: hardware concept, software architecture, and game logic. The architecture — hardware abstraction below, portable game logic above, platform-specific rendering at the top — is clean from the start.

### The product

The RGB Strip is a linear LED system that operates as both a programmable ambient light and a dedicated one-dimensional gaming platform. The product line is three strip units (S1, S2, S4 — 120 LEDs across 0.83 m, 2 m, and 4 m respectively), a hybrid wireless/wired controller (P1), a magnetic pogo-to-USB-C converter (C1), and extension cables (E1/E2). The fixed resolution of 120 pixels across all strip lengths — with only the physical spacing varying — is a foundational decision: the same game logic runs on every unit.

### The Game API

The programming interface is a single Haxe base class with a minimal footprint:

```haxe
class Game {
    pixels[120][3];      // LED buffer
    update();            // Frame update
    red/green/blue();    // Button handlers
    log(); beep();       // Debug/audio
}
```

Haxe compiles to JavaScript for fast browser prototyping and to C++ for the eventual hardware target — the same source runs in both environments without modification. A Makefile build system and a 120-pixel browser simulator close the loop: change Haxe, run make, refresh browser.

### MoodLight and STACK

MoodLight renders a continuous rainbow gradient across the strip, with the three buttons controlling animation speed. STACK is the more ambitious of the two: a snake of red, green, and blue dots drifts toward the player's fixed position; the player fires colour-matched bullets to remove the leading dot, while wrong-colour shots lengthen the snake by adding a new dot to the front. Thirty levels of progression — increasing dot count, shrinking gaps, rising speed — are defined and working. STACK is fully playable; MoodLight is complete.
