# 17 Jan 2026 – DeepSeek 3 – Sound system, controller redesign, and multi-game navigation

### The controller

The button system was overhauled from scratch. Three physical buttons (R, G, B = 0, 1, 2) now produce four distinct event types — Press, Hold, Release, ReleaseHold — giving games the full range of input they need. The `GameController` integration was simplified to a single `handleButtonEvent` method with proper binding and cleanup. Keyboard mapping (1→0, 2→1, 3→2) and touch-friendly visual buttons keep the simulator usable across devices.

### Sound

Audio moved out of the game layer and into a standalone JavaScript `Sound` class with a single `play(name)` method and a `SOUNDS` array. WAV files are used throughout for cross-platform compatibility. Each game maintains its own sound library; STACK gained shoot, hit, miss, success, and fail effects, plus per-dot click sounds.

### Navigation and structure

All games are consolidated into a single HTML file with a fixed nav bar, a clean menu system, and proper cleanup on game switching. The timing system was updated to `haxe.Timer.stamp()` and a `delay` system was added to the base `Game` class. Pacman movement uses press and release events. A minimal Playground game — static black-to-white gradient, empty button handlers — is in place as a clean starting template for future games.
