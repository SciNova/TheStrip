# 18 Jan 2026 – DeepSeek 3 – Build system and a Haxe C++ lesson

Makefile rules now compile each game individually to its own JavaScript file — `stack.js`, `pacman.js`, `moodlight.js`, `playground.js` — all running cleanly in the browser alongside `strip.js`, `styles.css`, and `index.html`.

One discovery worth noting: `haxe -cpp` does not produce a single `.cpp` file. It outputs a directory of multiple `.cpp` and `.h` files. There is no way to get a single self-contained C++ file from a Haxe class. The path to hardware will need to account for that.
