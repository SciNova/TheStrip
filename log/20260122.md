# 22 Jan 2026 – DeepSeek 3 – Base class enhancements, STACK v1.0, and debug panel

### Base class

The base `Game` class was extended with `uptime`, `time`, and `levelTime` counters, a `level` counter, and `startLevel()`, `nextLevel()`, and `restartLevel()` methods. A timing bug in STACK was fixed by separating `lastGameTime` from the base class's `lastFrameTime`, ensuring correct delta calculations.

### STACK v1.0

STACK was polished to v1.0. Sounds were renamed to a clean game-prefixed scheme — `stackGenerateDot`, `stackShoot`, `stackHit`, `stackMiss`, `stackLevelComplete`, `stackLevelFail`, `stackGameComplete`. Bullet timing was corrected to use `levelTime` directly. Snake initialisation was fixed to start at `120 - length()` rather than `120`. Level transitions were cleaned up with `defer(nextLevel, 4)` and `defer(restartLevel, 4)`, removing arbitrary `startLevel()` calls. The final level plays a victory sound and resets to level 0 after 30 seconds.

### Debug panel

A debug panel was added to the web interface showing `level`, `levelTime`, `uptime`, and `time`. Pacman was updated to use the new base class timing system.
