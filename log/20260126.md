# 26 Jan 2026 – DeepSeek 3 – Three.js simulation and Flask server

### Three.js

The Three.js 3D simulation was fixed and properly set up. Touch and mouse gesture controls were removed in favour of a clean keyboard scheme: arrows to orbit the camera, Shift+arrows to pan, Ctrl+up/down to zoom. The strip sits at the origin along the negative Z-axis (LED 0 at z=0, LED 119 at z=−119); the camera looks at the strip centre (z=−60) and opens directly above for a vertical display. F11 toggles fullscreen for recording.

### Flask

A single-file Flask app (`web.py`) was built with dynamic game loading via `/games/<game>` routes, string-based templates, and catch-all static file serving. Several bugs were fixed along the way: a template variable rendering issue, event listeners scoped to the container rather than the document, keyboard focus management, and a white CSS border around the canvas.
