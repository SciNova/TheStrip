# 31 Jan 2026 – DeepSeek 3 – Colour system refactored and App.hx namespace

`Game.hx` was renamed to `App.hx` as the central library file. The overengineered `Color` enum abstraction was eliminated and replaced with a lightweight `Colors` class of inline integer constants and a global `rgb(color:Int):Array<Int>` utility function. Games now need only `import App;` to get everything. All existing games were updated — Stack, Pacman, Playground, Dices, SimonSays, Race, Slots, Test — with Moodlight requiring no changes as it doesn't use colours directly. The integer-based system compiles to literal integers with zero runtime overhead and translates directly to C++ without abstraction layers.
